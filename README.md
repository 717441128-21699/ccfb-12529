# 助听器验配模拟系统

面向听力中心的**家属沟通工具**：导入老人听力图后，系统按公开发表的处方公式
计算 8 通道助听器增益、模拟轻声/大声分开的压缩、自动找出并压制啸叫频点，
生成两个试听版本——

- **版本 A（裸耳）**：老人现在实际听到的声音（阈值门限 + 响度重振 + 言语清晰度下降）
- **版本 B（助听）**：戴上助听器后听到的声音（WDRC 压缩 + 耳模泄漏补偿 + 啸叫抑制）

家属戴耳机 A/B 对比即可直观理解「老人为什么听不清」，不再误以为是不配合。
所有处理在本机完成，录音不外传。

## 四项验收指标与落实

| # | 指标 | 实现方式 | 自动化验证 |
|---|------|----------|------------|
| 1 | 8 通道增益与公开处方公式目标差 ≤3 dB | 完整实现 **NAL-R / NAL-RP / POGO / FIG6** 四个公开发表公式；65 dB SPL 锚点与线性公式严格一致，WDRC 按压缩比向轻/大声两侧展开 | `tests/test_1_prescription.py`：教材手工算例逐频点比对 + 8 通道端到端实测 |
| 2 | 开放/封闭耳模低频泄漏自动补偿 | 气孔建模为一阶高通（开放 fc=500 Hz、封闭 fc=150 Hz），按 STFT bin 统计每通道泄漏量并精确补偿，40 dB 安全封顶并告警 | `tests/test_2_occlusion.py` |
| 3 | 听损模拟体现言语清晰度下降 | 三重机制：①阈值门限（听不见的成分消失）②响度重振（幂律异常响度增长）③ERB 域频谱涂抹（频率选择性丧失，相邻谱峰混叠） | `tests/test_3_hearing_loss.py` |
| 4 | 1 分钟录音处理 ≤2 秒 | 全向量化 STFT 处理 + 时域带通 RMS 电平估计 + 稀疏化频谱涂抹；实测 60 秒音频约 **1.0–1.2 秒（50× 实时）** | `tests/test_4_perf_feedback.py` |

测试结果：`35 passed`，性能测试连续多轮稳定通过。

## 快速开始

```powershell
# 1. 安装依赖（本机已装可跳过）
py -m pip install -r requirements.txt

# 2. 跑全部验收测试
$env:PYTHONPATH='.'
py -m pytest tests/ -v

# 3. 命令行演示（生成 outputs/demo_unaided.wav 与 demo_aided.wav）
py -I scripts/demo_cli.py --preset 中重度高频陡降 --mold open --howl

# 4. 启动网页（浏览器访问 http://127.0.0.1:5000）
py -I webapp/app.py
```

网页操作：录入/套用听力图 → 选处方公式与耳模类型 → 上传录音（或用内置
类言语信号，可勾选注入啸叫）→ 点「开始验配」→ 戴耳机 A/B 试听。

## 关键设计说明

### 处方公式与 WDRC
- NAL-R 严格按 Byrne & Dillon (1986)：`IG(f) = X + 0.31·HL(f) + a(f)`，
  `X = 0.15·HL500 + 0.31·HL1k + 0.54·HL2k`；平坦 40 dB 听损 1 kHz 目标 53.4 dB，
  与 Dillon 教材表一致（测试断言）。
- WDRC 以 65 dB SPL 为线性锚点，按每通道压缩比向 50/80 dB SPL 展开：
  `G(L) = G(65) + (65−L)·(1−1/CR)`，保证输出变化量 = 输入变化量 / CR。
- 电平估计采用真实助听器架构：**时域带通滤波 + 分帧 RMS**，并带纯音检测
  分支（窄带信号用 STFT 峰值 bin + Hann 窗标定常数），宽带/窄带电平都准确。

### 耳模泄漏补偿
开放耳塞气孔大、低频泄漏重（fc=500 Hz 一阶高通），封闭定制耳模泄漏轻
（fc=150 Hz）。补偿量按每通道全部 STFT bin 的平均泄漏统计，等于多少漏多少，
单通道封顶 40 dB；触顶时前端明确提示「建议改用封闭耳模」。

### 啸叫处理（两道防线）
1. **验配侧**：按临界环路增益模型算每通道稳定余量，余量不足 6 dB 自动下调目标增益；
2. **信号侧**：对录音做谱峰检测（持续性 ≥40% 帧、锐度 ≥15 dB、500–7800 Hz），
   检出后用 RBJ 双二阶陷波器（Q=30、深度 20 dB，通带单位增益）精准压制。

### 裸耳听损模拟
不是简单衰减，而是按临界频带整体施加：低于听阈的成分门限静默；听阈以上用
幂律曲线模拟重振（听阈附近响度增长异常陡峭、高电平等响）；最后在 ERB 域
做高斯展宽，展宽量随听阈增大，直接体现「频率选择性下降 → 言语含糊」。

## 校准假设与适用边界
- 0 dBFS 校准为 100 dB SPL；真实设备应通过声级计重新标定 `audio.CAL_DB_SPL`。
- 听阈（dB HL）直接与 SPL 基准比较，省略了 RETSPL 频率修正（演示用途；
  临床版本应补入 ISO 226 RETSPL 表）。
- 临界环路增益表为开放耳模经验模型，实际值随耳塞/耳道个体差异变化。
- 本系统用于家属沟通与算法演示，不替代临床真耳分析（REM）与处方微调。
